# Two Sum

## 問題の要約

配列と変数Targetが与えられ、配列の中から2つの和がTargetになる組み合わせの指数を見つける

## 初見の印象

パワープレイでいけそう

## アプローチ

### 方針

配列の先頭から見ていき、次の要素を順番に足して、Targetsになったら答えの配列を返す

### 手順

省略

## 解法

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int[] answer = new int[2];
        for(int i = 0; i < nums.length; i++) {
            int currentNum = nums[i];
            for(int j = i + 1; j < nums.length; j++) {
                if (currentNum + nums[j] == target){
                   answer[0] = i;
                   answer[1] = j;
                }
            }
        }
        return answer;
    }
}
```

## 別解・改善案

HashMapを使うと、計算量がO(N)で済むらしい。

```java
import java.util.HashMap;

public class Solution {
    public int[] twoSum(int[] nums, int target) {
        HashMap<Integer, Integer> map = new HashMap<>();
        
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            
            // If complement exists, we found the pair
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            
            // Otherwise, store current number and index
            map.put(nums[i], i);
        }
        
        // No solution found (should not happen per problem constraints)
        throw new IllegalArgumentException("No two sum solution");
    }
}
```
